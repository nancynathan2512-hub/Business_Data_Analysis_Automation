# Business Data Analysis & Automation

## Overview

This project focuses on automating business data preparation, analysis, and reporting using Python.

The workflow takes business data through inspection, cleaning, transformation, and report generation. The aim is to reduce repetitive manual work and create a structured process that can be reused with business datasets.

## Project Workflow

Raw Data → Data Inspection → Data Cleaning → Data Transformation → Business Report → Insights

## Scripts

The `scripts` folder contains the Python scripts used in the project:

- `inspect_data.py` – inspects the dataset and checks its structure.
- `clean_data.py` – cleans and prepares the data for analysis.
- `transform_data.py` – transforms the prepared data into a usable format.
- `generate_business_report.py` – creates the business report workbook.
- `ai_insights.py` – generates additional insights from the prepared data.

## Output

The project generates a business report in Excel format:

`business_report.xlsx`
